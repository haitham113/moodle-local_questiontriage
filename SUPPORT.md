# Support and issue reporting

For general questions, documentation corrections and reproducible non-security
bugs, use the [public issue tracker](https://github.com/haitham113/moodle-local_questiontriage/issues).
This plugin remains an alpha; paid support entitlements, monitoring/response
commitments and a public maintenance policy are not finalized. No response-time
SLA, lifetime support or support for untested combinations is promised.

Students should first use their institution's normal support channel. Site
administrators can report a sanitized reproduction using invented data.

Include the plugin release/build, exact Moodle/PHP/database/theme versions,
role and relevant quiz/group/review settings, minimal reproduction steps,
expected/observed behavior, timestamp/time zone, and a sanitized screenshot if useful.
Explain whether native quiz answering, navigation or submission was affected.

Never post student feedback, private notes, answers, real account information,
credentials, cookies, sesskeys, tokens, configuration files or database dumps.
For potential vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

Compatibility claims require tests on the exact Moodle/theme combinations.
See [compatibility and evidence boundaries](docs/compatibility.md).
