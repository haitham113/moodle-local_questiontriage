# Security reporting

Do not post vulnerability details, assessment-access exploits or personal data
in public issues or pull requests. Use synthetic accounts/questions for any
reproduction and keep sensitive proof private.

A monitored private security-reporting route and maintenance/response commitments
are still being configured before public plugin distribution. This repository
does not yet advertise a working private vulnerability inbox or response SLA.
Existing private-alpha evaluators should contact their package supplier through
their established private project channel to request a reporting route before
sending sensitive details.

A useful private report describes the affected release, preconditions, role,
minimal synthetic reproduction, expected boundary and observed impact. Do not
send production database dumps, student explanations, staff notes, answers,
passwords or session tokens.

Public documentation does not establish Marketplace approval or a supported
commercial release. The current plugin is an alpha under evaluation.
